oop: object oriented programming system or structure
1) class
2) object
3) encapsulation
4) inheritance
5) polymorphism
6) aggregation
7) abstraction

------------------------------------
1) class :
   class is a userdefined data type which is contain similar
   and dis-similar data elements at single location.

   it same like structure.

   syntax:
    class <classname>
    {
        data member
        member functions
    };

2) object : object is an instance of class using of
          object we can access properties of class.

          <classname>  <objectname>;
          ---------------------------
visibility modes or access specifier :
 there are 3 visibility modes in c++

 1) public
 2) private
 3) protected

 1) public : we can access data member and member functions anywhere 
    out side the class.

2) private : only own class can access the properties of own class.

3) protected:
 only own class and child class can access the properties of class.
----------------------------------------

   constructor can't be written in private mode.

     };

destructor: means destroy object using of destructor does not

            syntax:
            class<classname>

4) inheritance:
  inheritance is a most powerfull concept of oop concept.

  inheritance means derived properties from one class to another class.

  there is a parent and child relationship between class its called 
  inheritance.

  inheritance provided reusability .

  using of inheritance we can reduce our code.
  and we can save our development time.

class A (parent)  (base)  (super)
   |
   v
class B (child)  (derived)  (sub)

syntax:
  class classname
  {
    data member
    member function
  };
  class classname: <access specifier> parentclass

5) polymorphism :
       poly means many and morphism means forms.

       polymorphism is derived from greek word.

       which means one class or more class has same name methods.

       there are mainly 2 types of polymorphism.

       i) method overloading
       ii) method overriding

       i) method overloading:
         one class can contain same name multiple methods
         with different arguments.
----------------------------------------------------
method overriding:

   when parent and child both have same name method 
   its called method overriding.
