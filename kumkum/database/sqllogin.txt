3) TRUNCATE : TRUNCATE command which mainly use to remove all 
              rows from the table.

in a simple language we can say that TRUNCATE command remove all 
from the table.

difference between drop and TRUNCATE.

drop : completly remove table from the database.
 
    after execution of drop command we can't find out table in memory.

TRUNCATE : using of TRUNCATE we can just deleting records from the table not 
         destroying table from the database.

  drop : remove data, remove structure ,remove table

  TRUNCATE : remove data, remain structure as it is and remain table as it is.

  syntax : TRUNCATE table <tablename>


// all table remove, regenarate table reset counter from 1.
  e.g.,

     id      name      subject      
     1       Anjali    python
     2       mittal    java 
    
     4

     by defualt increment by 1 when we execute TRUNCATE command 
     it reset counter from 1.

6) FOREIGN KEY : 
    which is mainly use to connect with another table .

    when we want to provide relationship between two tables we have to use foreign key

    create department
    (
        id int primary key auto_increment,
        d_name varchar(20)
    );
     
        1.IT
        2.ADMIN

    create emp
    (
        id int primary key auto_increment,
        name varchar(20),
        d_id int,
        foreign key (d_id) references department(id)
    );
